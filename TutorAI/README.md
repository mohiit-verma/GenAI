# TutorAI RAG

This project modularizes the TutorAI_RAG notebook into a Python package.

## Structure
```
TutorAI_RAG_app/
  requirements.txt
  run_app.py
  tutorai_rag/
    __init__.py
    config.py
    utils.py
    vector_index.py
    llm.py
    dashboard.py
```

## Run
```bash
pip install -r requirements.txt
python run_app.py
```
